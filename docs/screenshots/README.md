# Screenshots

PNG screenshots used by the main `README.md`. Captured from the desktop app in
the dark theme at a window width of about 1200px.

| File | Screen |
| ---- | ------ |
| `edit.png` | Edit email with the "Edit with AI" panel (README hero) |
| `settings.png` | Settings with AI provider + SMTP |
| `brief.png` | Campaign brief with the "What gets sent to AI" panel |
| `bulk-send.png` | Bulk send with dry-run, recipients and suppression |

To add more, run `npm run tauri dev`, load sample data with **Load test data
(dev)** on the Welcome screen, and save the PNG here.
